# 🌿 Muhiyudeen & Fathima - Wedding Invitation Website

A responsive, fluid Islamic wedding invitation website built with pure HTML5, CSS3, JavaScript, and an Antigravity floating petals physics engine.

## 🚀 Deploying to GitHub Pages

This project is 100% client-side and static, making it ready for instant deployment on GitHub Pages.

### Quick Setup:

1. **Commit and Push** your code to a GitHub repository:
   ```bash
   git add .
   git commit -m "Initial commit: Wedding invitation website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on **GitHub.com**.
   - Navigate to **Settings** > **Pages** (under the "Code and automation" section in the left sidebar).
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.

3. **Visit Your Live Site**:
   - Within 1–2 minutes, your website will be live at:
     `https://<your-username>.github.io/<repo-name>/`
